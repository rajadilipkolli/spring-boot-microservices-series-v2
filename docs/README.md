# Architecture & Engineering Documentation

Welcome to the engineering documentation for **Spring Boot Microservices Series V2**.

---

## Documentation Sections

- **[Specification-Driven Development (SDD)](./sdd/README.md)**: The authoritative engineering specifications for all microservices, including domain models, business rules, API contracts, workflows, and operational quality attributes.
- **[Architecture Decision Records (ADR)](./adr/)**: Formal records documenting significant architectural decisions, alternatives evaluated, and adopted designs across the platform. Key ADRs include:
  - [ADR-001: Kubernetes Deployment Strategy](./adr/ADR-001-Kubernetes-Deployment-Strategy.md)
  - [ADR-007: Secrets Management and ESO](./adr/ADR-007-Secrets-Management-External-Secrets-Operator.md)
  - [ADR-014: Service Mesh & mTLS Evaluation](./adr/ADR-014-Service-Mesh-And-mTLS-Evaluation.md)
  - [ADR-015: Kubernetes Gateway API and Envoy Gateway Architecture](./adr/ADR-015-Kubernetes-Gateway-API-And-Envoy-Gateway.md)
- **[Operational Runbooks](./runbooks/)**: Incident triage, alerting procedures, disaster recovery protocols, and operational playbooks for platform engineers.
