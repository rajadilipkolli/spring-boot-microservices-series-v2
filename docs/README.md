# Architecture & Engineering Documentation

Welcome to the engineering documentation for **Spring Boot Microservices Series V2**.

---

## Documentation Sections

- **[Specification-Driven Development (SDD)](./sdd/README.md)**: The authoritative engineering specifications for all microservices, including domain models, business rules, API contracts, workflows, and operational quality attributes.
- **[Architecture Decision Records (ADR)](./adr/)**: Formal records documenting significant architectural decisions, alternatives evaluated, and adopted designs across the platform.
- **[Operational Runbooks](./runbooks/)**: Incident triage, alerting procedures, disaster recovery protocols, and operational playbooks for platform engineers.
